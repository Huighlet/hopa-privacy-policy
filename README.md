# HOPA School Reports - Privacy Policy

Statutory privacy policy documentation for the **HOPA School Reports** mobile application, published via GitHub Pages.

## Live Policy
- **Policy URL:** [https://huighlet.github.io/hopa-privacy-policy/privacy-policy.html](https://huighlet.github.io/hopa-privacy-policy/privacy-policy.html)
- **Application Portal:** [https://huighlet.github.io/hopa-download/download.html](https://huighlet.github.io/hopa-download/download.html)

## Summary of Data Practices
- **Offline Storage:** All school, student, and grading data is stored strictly on the local device.
- **Zero Third-Party Telemetry:** No user analytics, tracker SDKs, or remote profiling are incorporated.
- **Data Ownership:** School administrators retain complete sovereignty over all stored and exported records.
